## Skill Steps (Ordered Actions)

### Step 1: Validate Credentials
- **Input**: API key and private key from `.env` file
- **Output**: Verified credential status or error identification
- **Completion Criterion**: Credentials validated or specific error identified
- **Action**: Read `.env` file, extract `COINBASE_API_KEY` and `COINBASE_API_SECRET`

### Step 2: API Authentication
- **Input**: Validated API key and private key
- **Output**: Authenticated session token or authentication failure
- **Completion Criterion**: Successful authentication or documented failure
- **Action**: Use EC private key to sign authentication requests per Coinbase Advanced Trade API spec

### Step 3: Retrieve Balance Data
- **Input**: Authenticated session
- **Output**: Balance information for specified assets/currencies
- **Completion Criterion**: Balance data retrieved or API error documented
- **Action**: Call Coinbase `/balances` endpoint with authenticated session
- **Expected Output Structure**: JSON with currency amounts, available balances

### Step 4: Process and Present Results
- **Input**: Balance data from API
- **Output**: Human-readable balance summary or structured data for further processing
- **Completion Criterion**: Balance information presented in requested format
- **Action**: Parse API response, extract relevant currency balances, format for user display or downstream processing

### Step 5: Error Handling & Recovery
- **Input**: API errors, rate limits, authentication failures
- **Output**: Documented error state or retry plan
- **Completion Criterion**: Error documented or retry strategy implemented
- **Action**: Handle common errors (invalid key, rate limiting, network issues), implement retry with backoff
