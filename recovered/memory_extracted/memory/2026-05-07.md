### Lessons Learned
1. **Always save the nonce** when creating API keys - needed for recovery
2. **Python client works better** than TypeScript for Polymarket (TS client returned empty `apiKey` fields)
3. **Wallet addresses must match**: signing key → API key wallet → funder address
4. **pUSD is Polymarket's new system** - balance checks need different API params
5. **Old bots should be retired** - they have hardcoded balance checks that break on API changes
6. **Prediction markets ≠ crypto exchanges** - markets close after events resolve, not 24/7 like spot trading
